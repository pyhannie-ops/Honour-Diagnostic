BEFORE: how it often looks

New starter access

When HR sends the email about a new person starting you need to go in the system and make them a profile and also check with their manager what they need, usually the standard set but sometimes finance ones too, then you put the details in and save it and it should send them an email, if it doesn't then do it again or ask IT. Don't forget to tick the box for the training one. The password thing is automatic but sometimes you have to reset it so go to the users page, also tell the manager when its done. Make sure its approved first (see Sarah) otherwise it gets rejected and we have to start over. Use the new template if there is one.

What makes this hard to use
  • No purpose, owner or review date.
  • The steps are buried in one paragraph, in no clear order.
  • One thing has three names: profile, account, user.
  • It never says where to click or what you should see.
  • Approval depends on knowing who “Sarah” is.
AFTER: clear, repeatable, error-free

Set up system access for a new starter

Owner: IT Service Desk  |  Last reviewed: [date]  |  Applies to: ExampleERP portal
Purpose

Give a new starter the access they need on their first day, with their manager’s approval.

Before you start
  • The approved New Starter Form from HR.
  • The manager’s confirmation of required access: Standard, or Standard and Finance.
  • You hold the Service Desk Administrator role.
Steps
  1. Open the ExampleERP portal and select Users › Add user.
  2. Enter the details from the approved form: full name, work email, start date and department.
  3. Under Access profile, select Standard. If the manager asked for Finance access, also select Finance.
  4. Tick Assign mandatory training.
  5. Select Save.Expected result: A confirmation message appears, and the new starter receives a welcome email within 5 minutes.
  6. Email the manager to confirm the access is ready.Note: Passwords are generated automatically. Never send a password by email.
If something goes wrong
ProblemWhat to do
No welcome email after 5 minutesSelect Users › the user › Resend welcome email.
Request rejectedCheck the form has manager approval, then submit it again.
Still stuckContact IT Support.
